# Exploratory Data Analysis - Iris Dataset

## Objective
Analyze the Iris dataset to discover patterns, trends, and relationships between variables.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Key Findings
- The dataset contains 150 observations.
- There are no missing values.
- Petal length and petal width have a strong positive correlation.
- Petal measurements are useful for distinguishing Iris species.

## Conclusion
The EDA helped identify important patterns and relationships in the Iris dataset.
